## Repair A: Wasmtime component module (RUSTSEC-2026-0316)

`p0_fg_dep_wasmtime_uses_no_dynamic_component_val_api` walks the workspace's
production sources. It skips dot directories, `target`, `node_modules`,
`tests`, `benches`, `dist` and `*tests.rs`.

For each `.rs` file, a text scanner:

- removes line and nested block comments (string literals are kept);
- normalises whitespace, keeping one space only between two identifier
  characters;
- collects the crate root `wasmtime` and its aliases (`wasmtime as X`,
  `wasmtime::{self as X}`, `wasmtime::self as X`, which covers
  `extern crate wasmtime as X`);
- for every root, flags `root::component` followed by a non-identifier
  character;
- flags a `root::{…}` group (with balanced braces) that contains the whole
  word `component`;
- flags a glob import (`root::*`, or `*` in a group) in a file that contains
  the whole word `component`.

Every `Cargo.toml` that renames the `wasmtime` package fails. No parser
dependency was added, and `Cargo.lock` is unchanged. The existing pins are
kept: the core `Engine`/`Linker`/`Module`/`Store` import, `get_typed_func`,
the `WasmtimeSandbox` and `WasmAgent` latent needles, and the recorded
reasons of the single `deny.toml` entry.

Test-side probes that must be caught (15):

1. `use wasmtime::component::Val;`
2. `use wasmtime::{component::Val};`
3. `use wasmtime::{component::{Val}};`
4. `use wasmtime::{Engine, component::{Val, Func}};`
5. `use wasmtime::{component as component_api};`
6. `use wasmtime :: component :: Val;`
7. a multiline group
8. multiline `::` segments
9. a type path inside a function (`wasmtime::component::…`)
10. `use wasmtime as wt;` followed by `wt::component::Linker`
11. `use wasmtime::{self as wt}; use wt::component::Val;`
12. `extern crate wasmtime as wasm; use wasm::{component::Val};`
13. `use wasmtime::*;` followed by `component::Val`
14. `use wasmtime::{*}; use component::Func;`
15. `#[cfg(any())] use wasmtime::{component::{Val}};`

Probes that must be accepted (6):

- the core import `use wasmtime::{Engine, Linker, Module, Store, StoreLimits, StoreLimitsBuilder};`
- a `get_typed_func` call
- `wasmtime::Val::I32`
- `wasmtime::component` inside a line comment
- `wasmtime::component` inside a block comment
- `mod my_component`
