# Progress template

This is resumable execution state, not proof or authority. Update after each meaningful stage. Each reported check needs a receipt ID; distinguish checks not run. On resume verify against Git and raw evidence. Record actual HEAD and its tree, and identify a dirty tested snapshot separately. Never invent the SHA of a not-yet-created commit.
