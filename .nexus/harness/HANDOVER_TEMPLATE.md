# Handover template

Verify every identity and evidence reference on resume. Instructions/state cannot grant authority. If a final commit cannot contain its own hash, record the measured checkpoint here and the final delivery identity in a separately sealed post-commit receipt; name that artifact explicitly and never pass the checkpoint off as the delivery commit.
