# Nexus review

Read root `AGENTS.md`, `.nexus/harness/POLICY.md` and the explicit mission path
supplied by the Architect. Then read and follow the canonical
[review procedure](../../../.nexus/harness/procedures/review.md).
Resolve the link from this skill directory; root paths above are repo-relative.

Use the mission's canonical PROGRESS, EVIDENCE, receipts, REVIEW and HANDOVER
records as directed by that procedure. This adapter only routes the workflow;
it supplies neither a separate policy nor authorization.
