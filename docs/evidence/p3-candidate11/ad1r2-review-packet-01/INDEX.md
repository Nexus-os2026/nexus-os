**What this is.** One evidence-transport packet for the independent audit of the AD-1-R2 draft and of the raw C1/C25
witness evidence. It is documentation only. Its commit is an evidence-transport commit, not an engineering baseline,
and not the final commit of any mission. AD-1-R2 is a DRAFT — NOT ACCEPTED — NOT ADOPTED — NOT APPLIED. Nothing here
is a run, a mutation kill, an acceptance or an adoption.

**Source baseline.** Parent commit `42dd1bd1cf21ffdea5968b256d2983f6575fab5b` (tree
`7ac6bb21430d15b17e3723b217b20a49dccf8282`), the witness commit published on
`refs/heads/review/p3-c11-d2a1-ad1r1-witness-01`. Every file outside this directory is unchanged from it.

**Originals.** Every file under `evidence/` is a byte copy of the file at the same relative path under the evidence
root `/home/nexus/nexus-audits/claude-architect/` (outside the repository), which stays authoritative and sealed.
Its sha256 below was checked against the source file and against the origin directory's sealed `SHA256SUMS` before
copying. Each origin's `SHA256SUMS` is transported byte for byte; it lists files not transported (coverage below), so
a transported subset does not verify an entire origin directory.

**Verify.** From this directory: `sha256sum -c TRANSPORT-SHA256SUMS` checks every packet file (it covers every file
but itself). For one origin, from `evidence/<origin>/`: `sha256sum -c --ignore-missing SHA256SUMS` checks the
transported subset against the sealed list. AD-1-R2's checks re-run with `ad1r2/tools/check-ad1r2.py`.

**Not in the packet:** binaries, executables, build directories, applied mutant source files, credentials, archives.
