C. FORMAL PROJECTION AND TRACE CORRESPONDENCE
  Key = PRE(pi) || [a] || POST(pi): encode writes adm as one byte, and nothing else depends on it.
  Equivalence: (pi,a) ~ (pi',a')  iff  pi = pi', i.e. the keys are equal on every byte but the admission byte.
  Theorem 1 (product). nodes(G) = { (pi,a) : pi in R_Q, 0 <= a <= N }, where R_Q is the set of states reachable
    without ADM. Proof: delete ADM edges from any path, or prepend N-a ADM steps. Both directions rest on L-A
    (no other actor reads adm) and L-B (ADM writes only adm, is enabled iff adm > 0, is non-fault, consults no
    choice, and is observed as OBS(pi)).
  Quotient Q = G/~ with each ADM edge (a self-loop on its class) replaced by the observation OBS(pi), D1
    judged at adm 0, and L1 judged on non-ADM edges. As edges, the self-loops would be spurious L1 cycles.
  Traces. A Q path is literally a G path at counter N; the original trace() replays it. Mapping:
    state violation       -> the same trace
    non-ADM transition    -> the same trace plus that edge
    admission violation   -> the trace plus one ADM edge
    D1                    -> the trace plus N ADM edges, reaching (pi, 0)
    L1                    -> the trace to the cyclic state, at counter N
  Shortest lengths are preserved except D1: the quotient finds a D1 failure N steps earlier, and the mapped
  trace adds those N steps back.
  Assumptions: AQ1 the model as at 244c5b23 (or a mutant satisfying M1-M3); AQ2 adm_kept None (checked);
  AQ3 no hook callback in the exploring thread; AQ4 step determinism; AQ5 complete runs only; AQ6 model
  state-safety only — not real executions, not ledger durability, not A-1/A-2, not contract 6.2/6.3.
  Not claimed: equal transition counts, equal cost, an equal first-reported property, anything about an
  INCOMPLETE run. The relations between the two graphs are T_G = (N+1)T_Q + N|R_Q| and F_G = (N+1)F_Q.
