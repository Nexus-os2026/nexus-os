1. LEMMA E CARRIES OVER — the new paths read and write only caller-free data
=====================================================================================================
Lemma E (GC-SYMMETRY-01 section 3) was argued by inspection of every branch condition, every equality on
identity-bearing data and every choice point of `step`, transitively through P, for any reachable world of a
configuration meeting its preconditions; only clause (g) uses reachability, and (g) depends only on acks = 0,
malformed = false and gating_conflict = false. F-PT and F-B meet those. What remains is to show that the code
paths F-PT and F-B reach and F-3 does not (A4-1, A4-2, B-1..B-5) are themselves caller-free.

E-PT  A4-1/A4-2 read: config.blanket_uncertain; the writer's or settlement's ticket (Counted{persistence,
      conflict_member}: no caller); the members (fact indices 0/1). They write: table.class[f], table.debt
      (via set_class), ghost.unrecorded bit f. pi fixes all of these (pi touches no fact, table, ticket or
      `unrecorded`: GC-SYMMETRY-01 S5, mirror_world M 6266-6344). No oracle call, no hook event, no store
      verb. Mechanical check: M 2375-2385, 2389-2399, 2510-2638, 2777-2788 contain no gating_key,
      gating_member, gating_of, original_of, Gating/Correction/Other/Explanation row, Actor::Gc, w.gc,
      ghost.issued/told, bit(g) or adm read (grep, receipts/stage2/01).                          PROVEN
E-B   B-2 compares only fact identities: well_formed tests id equality and Part equality between batch
      members (all facts; P 815-833); constraint's `earlier.any(|m| m.part == prepared)` (P 867) compares fact
      parts (commitment kind 9, fixed by mx). classify's other reads are Lemma E (b) equalities already
      covered (row, known, refusals.get, X's original). Insert sequences are rows.len() + pending.len()
      (M 718), caller-free. Holdings (M 671-694) branch on the count of pending fact rows. Members are
      visited in batch order 0, 1 (fact order, fixed by pi). B-1, B-3, B-4, B-5 read and write only fact
      indices, the writer's position/ticket, conflicted_e6 and config.batch. The actor list depends on
      config.batch only; mirror_edge (M 6363-6373) finds Gc(1-g) by position, so G1/G2 at 3/4 is handled.
                                                                                                  PROVEN
E-R   P never iterates the refusal table in key order: its uses are len (P 1156), get (1162, 1575), insert
      (1221, 1533), remove (1560, 1943) — key equality only (re-checked for this stage). The only ordered
