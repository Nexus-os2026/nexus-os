C. COMPLETE TRANSFORMATION DEFINITION
=====================================================================================
sigma (callers) g -> 1-g; sigma (originals) 0,1 fixed, 2<->3.
mirror_x32 on a 32-byte simulation value, typed by its first byte: 2 (gating record /
  G's other content) and 6 (correction about G): second byte g -> 1-g; 5 (explanation
  of original o): o -> sigma(o); 1, 3, 4, 9 (fact, holder, Prepared, commitment):
  unchanged; anything else (7 = acknowledgement, or unknown): refused.
RecordKey: id and digest by mirror_x32. Member: key, part's commitment. Cause: every
  id/digest by mirror_x32, every key by RecordKey, every sequence kept. Occupant: Gating
  record, Correction about, Explanation original+cause; Acknowledgement refused.
SimRow: Gating(g), Correction(g,e), Other(g) -> 1-g; Explanation(o) -> sigma(o);
  Prepared/Holder/Fact unchanged; Acknowledgement refused. Rows stay in place.
World (destructured whole, so a new field breaks the build until placed): core U/C/X
  occupants; refusal table rebuilt (size asserted); every row; settlement's held
  Lookup::Conflict(Known::Cause); gc.swap(0,1); ack must be empty; adm_kept must be None;
  ghost.issued, ghost.told bits 0<->1; all else unchanged.
Keys: mirror(k) = encode(mirror_world(decode(k))). canonical = min_bytes(k, mirror k).
Edges: actor Gc(g) -> Gc(1-g) by position in actors(config); choices kept.
Guard: at every expanded key, mirror(mirror(key)) == key; expand(key) and
  expand(mirror(key)); per actor, the second's items must equal the first's with edge

  mirrored; same state-violation names; D1 judged alike. Difference: panic
