## Frozen encoding

Contract: append `page_facts` after `deliverable`; absent fields are omitted.
PageFacts field order: `name`, `hours`, `phone`; unknown fields refused.
LaneInput: append optional `builder_input` after `prior_outputs`; absent omitted.
PageBuildInput field order: `contract_hash`, `invocation`, `content_sha256`.
Skipped payload fields: `note`, `facts`. No deserializer or public constructor.
Its content digest is raw SHA-256 of `nexus-m3/page-build-input/1\0` followed
by compact serde_json of `{note: Note, facts: PageFacts}` in that field order.
Unlike the retained legacy hash helper, this digest has no length prefix.
The NUL is one byte, not two printable characters. The oracle pins both
literal minimal payload bytes and their independently computed SHA-256.
The serialized outer identity binds contract hash and invocation (mission, seq).
Preparation validates the full contract and snapshot before LaneInvoked,
reservation accounting, or dispatch. Borrowing grants no broker authority.

The existing contract and lane hash domains/length framing are unchanged.
The legacy JSON fixtures and their independently computed hashes are literal
constants in m3d_inputs.rs, not expectations regenerated by the implementation.
Private contracts retain full present facts; lane serialization retains identity
only. Debug shows no fact/note values. MissionSummary/confirmation are intended
Owner display surfaces, with the broker's own FactsView and facts hash.

## Frozen admission

Facts-present is the page discriminator. Legacy non-page behavior stays intact.
Exactly the six V0..V5 pairs from RULING Q1, in order; oracle literals independent
of the production registry. Any criterion modification returns
`criterion_not_checkable` (ContractError::CriterionNotCheckable).
One nonblank note, label `notes`: otherwise `page_note_invalid`.
Existing contract credential, plainness, 40-line and 1,792 rendered-byte checks
remain mandatory; label `notes` leaves 1,777 text bytes.
ApprovedFacts construction and Ca readiness precede consent and calls:
`facts_not_page_ready` (ContractError::FactsNotPageReady).
Rendered facts use `name: ...`, one `hours: ...` per line, `phone: ...`, joined
with LF and no final LF. Rendered note is `--- notes ---\n{text}\n`.
Combined >2,432 returns `notes_and_facts_too_large`.
Changed snapshot content/hash, outer hash or invocation returns
`page_input_identity` (ContractError::PageInputIdentity).
Input failure is never a model correction. No new persistent event/code format.
